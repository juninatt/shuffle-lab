# ShuffleLab

ShuffleLab is a Java playground for exploring and comparing card shuffling techniques.

The goal is to model real-world shuffle operations, simulate different levels of player skill, and measure how effectively various shuffle routines randomize a deck of cards.

Current features:

* Standard 52-card deck generation
* Deck splitting with configurable tolerance
* Perfect riffle shuffles
* Human-like riffle shuffles
* Validation of riffle packet constraints
* Comprehensive unit tests using JUnit 5 and AssertJ

Planned features:

* Cut operations
* Overhand shuffles
* Shuffle routines combining multiple operations
* Statistical analysis of shuffle quality
* Performance benchmarking

This project is primarily an experiment in object-oriented design, testing practices, and card shuffling simulation.
